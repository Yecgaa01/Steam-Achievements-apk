### Steam Achievements

## The app includes the following features:

* Displays your Steam profile name and avatar
* Lists all games available in your Steam library
* Tracks and shows your total playtime per game
* Displays the exact achievement completion progress percentage for each game
* Lists both unlocked and locked achievements separately
* Allows searching for specific achievements by name, description, or identifier
* Filters achievements by all, unlocked, locked, or hidden status
* Reveals hidden achievement descriptions when available
* Masks hidden achievement details by default and reveals them with a single tap
* Displays global achievement rarity percentages when available
* Sorts the game library alphabetically (A-Z), recently played, completion percentage and total playtime
* Hides games that do not have any achievements
* Hides games with 0% completion progress
* Filters out non-game items from the Steam library (WIP)
* Allows manually hiding games and restoring them later
* Toggles the main screen view to display only manually hidden games
* Resets and restores all manually hidden games at once through settings
* Provides a manual synchronization feature
* Caches data locally to prevent reloading the entire library every time the app opens
* Checks for new app updates directly from the "About" tab using GitHub Releases
* Downloads the latest APK file directly within the app when an update is found
* Triggers the native Android package installer automatically to confirm updates
* Saves your SteamID64 and Steam Web API key safely on local device storage only
* Features an experimental option to group and separate achievements by DLCs or updates
* Allows a quick long-press on any game to reload its specific progress, hide it, or unhide it
